# Launch checklist

Before making the repository public and enabling GitHub Pages:

- [ ] Run `quarto preview` and inspect every page.
- [ ] Run `quarto render` and make sure the `docs/` directory is created.
- [ ] Check that `docs/index.html` exists.
- [ ] Check that the CV download works locally.
- [ ] Verify your preferred public email address.
- [ ] Verify the University of Passau, CALC Lab, ORCID, Google Scholar, and GitHub links.
- [ ] Review the publication list against your latest CV and Scholar/ORCID records.
- [ ] Decide whether to keep the CALC-hosted profile photo or store a local copy in `images/`.
- [ ] Remove anything from the repository that you do not want to become public.
- [ ] Commit and push the latest source files and rendered `docs/` files.
- [ ] Change repository visibility from Private to Public if using GitHub Free.
- [ ] In GitHub: Settings > Pages > Build and deployment.
- [ ] Set Source to `Deploy from a branch`.
- [ ] Set Branch to `main` and Folder to `/docs`.
- [ ] Save and wait for the deployment to complete.
- [ ] Visit `https://cymelo92.github.io` in a private/incognito browser window.
